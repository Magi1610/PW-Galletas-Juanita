# PW Galletas Juanita

Sitio web de Galletas Juanita. React + Vite, consume la API [Cookiexpend-API](https://github.com/Magi1610) como backend.

## Quick start

```bash
npm install
cp .env.example .env   # ajusta VITE_API_URL si tu backend no corre en localhost:8000
npm run dev
```

Para estructura del proyecto, variables de entorno, comandos disponibles y flujo de ramas/PRs, ver [docs/onboarding.md](docs/onboarding.md).

## Stack

- [React](https://react.dev/) 19 + [Vite](https://vite.dev/)
- [React Router](https://reactrouter.com/) para el ruteo
- CSS plano por componente (`src/styles/*.css`), sin framework de utilidades
